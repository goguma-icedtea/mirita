# Mirita Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 브랜드 자료를 보존한 실행 가능한 경로 관리·도착 안내·웹 푸시 PWA를 비공개 GitHub에 작성한다.
**Architecture:** Node.js HTTP API, 단일 인스턴스 JSON 저장소, 서울 버스 어댑터, 서버 알림 스케줄러, 동일 출처 ES 모듈 프런트엔드.
**Tech Stack:** Node.js 24 builtins, Web Crypto/Node crypto, HTML/CSS/JavaScript, node:test, Playwright.
**Spec:** docs/superpowers/specs/2026-10-19-mirita-design.md

## Global Constraints
- primary #2463C5, bg #F3F8FF, text #163465, radius 8px.
- 실시간 인증키 없음은 체험 모드로 표시. 자동 알림 비활성.
- 도보 1~60분, 여유 1~10분, 경로 최대 10개.
- 로그인 없이 기기 쿠키로 격리. 비밀키 저장소 커밋 금지.

## Review Focus
- 서버 저장 실패 시 기존 데이터 유지 → store 재시작과 실패 테스트.
- 다른 기기의 경로 ID 요청 → HTTP 404 통합 테스트.
- 서울 API 인증·빈 값·비정상 응답 → transit 테스트.
- 서울 자정 부근과 주말 → scheduler 시간 테스트.
- 푸시 서비스 만료·재시도·목적지 위조 → push/scheduler 테스트.
