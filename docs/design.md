> 상태: v0.1 디자인 제안 · 2026-10-13  
> 근거: `brand.md`, 제공된 `mirita_keyvisual.png`, `mirita_logo.png`  
> 주의: `brand.md`에 '컬러 장면', '말투 형용사 3개', '무드 명사 5개', '금지어' 및 별도 `design.md` 템플릿은 명시되지 않음. 아래 해당 항목은 **제안**이며, 공식 브랜드 규칙으로 확정된 것이 아님.

## 0. 브랜드와 디자인 원칙

- **핵심 과업:** 출근 경로를 입력하면 버스 도착 사전 알림을 받는다.
- **서비스 약속:** 정류장까지 이동 시간을 고려해 버스 도착 30분 전부터 안내한다.
- **시각 장면(제안):** 맑은 아침 하늘, 파란 버스 안내, 여유 있는 출근길. 키 비주얼의 파란색·흰색·밝은 하늘색을 참고.
- **말투 형용사(제안):** 친절한 · 명확한 · 차분한.
- **무드 명사(제안):** 아침 · 하늘 · 여유 · 신뢰 · 안내.
- **문구 원칙(제안):** 짧은 존댓말, 사용자 행동과 결과를 구체적으로 표현, 확인되지 않은 도착 정확도를 보장하지 않음.
- **금지어:** 원본 `brand.md`에 지정 없음. 임시 회피 표현(제안): `무조건`, `100% 정확`, `절대 안 늦어요`, `지금 당장`, `실패`.

**근거:** `brand.md`는 버스를 놓친 불안을 사전 알림으로 줄이는 경험을 핵심 가치로 제시한다.

## 1. Color

### Primary 후보 — 흰색 글자 대비 검증

| 구분 | HEX | 흰색(#FFFFFF) 대비 | WCAG AA 일반 텍스트 4.5:1 | 키 비주얼과 조화 | 결정 근거 |
|---|---|---:|---|---|---|
| **A · 최종 권장** | **`#2463C5`** | **5.73:1** | **통과** | 자연스러움 | 키 비주얼의 선명한 블루를 유지하면서 버튼 가독성을 확보 |
| B · 밝은 블루 | `#276FE0` | 4.73:1 | 통과 | 자연스러움 | 시각적 활력은 크지만 대비 여유가 비교적 작음 |
| C · 딥 네이비 | `#163465` | 12.26:1 | 통과 | 다소 무거움 **(어색할 후보)** | 로고의 진한 글자와 통하지만 밝고 경쾌한 아침 장면의 주조색으로는 무거움 |

- **선택:** `primary = #2463C5`
- **사용:** 핵심 CTA, 선택 상태, 알림 관련 주요 아이콘.
- **주의:** 대비 수치는 표준 sRGB 상대 휘도 기반 계산값이며, 흰색 텍스트 기준이다. 큰 글자뿐 아니라 일반 텍스트 AA 기준을 충족한다.

**근거:** 키 비주얼은 밝은 블루·화이트가 주조이고, `brand.md`는 빠른 설정과 신뢰감 있는 안내를 우선한다.

### Background

- **`bg = #F3F8FF`**
- **HSL 명도:** 약 **97.6%** (95% 이상 충족)
- **사용:** 전체 페이지 배경, 빈 상태 배경. 카드와 입력 필드는 흰색 사용.

**근거:** primary와 같은 파란색 계열을 매우 옅게 사용해 맑은 아침 하늘의 분위기를 유지한다.

### 최종 색상 토큰

```css
:root {
  --color-primary: #2463C5;
  --color-bg: #F3F8FF;
  --color-surface: #FFFFFF;
  --color-text: #163465;
}
```

- **실사용 색상: 총 4개** (primary 후보 B는 비교용으로만 표시하며 토큰에 포함하지 않음).
- **상태 전달:** 에러는 색상만으로 표현하지 않고 제목·설명·아이콘을 함께 사용한다. 추가 에러 색상은 현재 정의하지 않는다.

**근거:** 기존 키 비주얼의 블루·네이비·화이트 체계 안에서 5색 이하로 유지한다.

## 2. Typography

| 용도 | 서체 | 출처·라이선스 확인 기준 | 적용 예시 | 선정 근거 |
|---|---|---|---|---|
| Heading | **Gowun Dodum (고운돋움)** | Google Fonts · SIL Open Font License 1.1 (배포 전 최신 조건 확인) | 24px / 700 / 1.35 | 부드러운 획이 **친절한·명확한·차분한** 말투와 조화 |
| Body | **Noto Sans KR** | Google Fonts · SIL Open Font License 1.1 (배포 전 최신 조건 확인) | 16px / 400 / 1.55 | 높은 한글 가독성이 **친절한·명확한·차분한** 안내를 지원 |

```css
:root {
  --font-heading: 'Gowun Dodum', sans-serif;
  --font-body: 'Noto Sans KR', sans-serif;
}
```

**근거:** 출근 중 짧게 읽는 정보는 장식보다 읽기 쉬운 한글과 명확한 위계가 중요하다.

## 3. Corner radius

- **선택: `8px`** (`0 / 8 / 999` 중 8)
- **적용:** 주요 버튼, 입력 필드, 카드, 빈 결과 안내 영역.
- **무드 연결:** 아침의 부드러움, 하늘의 개방감, 여유의 편안함, 신뢰의 정돈감, 안내의 명료함.

**근거:** 0은 지나치게 딱딱하고 999는 장식성이 강할 수 있어, 8px이 친근함과 실용성의 균형에 적합하다.

## 4. UX Writing

### 버튼 기본 문구 2개

| 위치 | 문구 | 근거 |
|---|---|---|
| 경로 입력 CTA | **이 경로로 알림 설정하기** | 사용자가 수행할 행동과 결과를 직접 설명 |
| 설정 완료 CTA | **완료** | 저장 성공 이후 다음 행동을 짧게 마무리 |

### 에러 기본 문구 2개

| 상황 | 문구 | 근거 |
|---|---|---|
| 경로 저장 실패 | **알림을 설정하지 못했어요. 입력한 경로는 유지했어요. 다시 시도해 주세요.** | 문제와 보존된 상태, 복구 행동을 차분하게 안내 |
| 알림 권한 거부 | **알림이 꺼져 있어요. 버스 도착 안내를 받으려면 기기 설정에서 알림을 켜 주세요.** | 기능 제약과 해결 방법을 구체적으로 안내 |

### 빈 화면 기본 문구 2개

| 상황 | 문구 | 근거 |
|---|---|---|
| 버스·정류장 검색 결과 없음 | **검색 결과가 없어요. 버스 번호나 정류장 이름을 바꿔 검색해 보세요.** | 사용자 잘못을 탓하지 않고 재검색 방법을 제시 |
| 저장된 경로 없음 | **저장된 출근 경로가 없어요. 경로를 입력하면 버스 도착 알림을 설정할 수 있어요.** | 현재 상태와 다음 행동을 연결 |

**근거:** `brand.md`의 기존 표현인 ‘검색 결과가 없어요’, ‘이 경로로 알림 설정하기’, ‘완료’를 유지하고, 추가 문구도 짧은 존댓말과 실행 가능한 안내로 작성했다.

## 5. 핵심 화면 적용 규칙

1. **출근 경로 입력:** `bg` 배경, 흰색 입력 카드, `primary` CTA, 8px 모서리. 출발지·정류장·버스 노선은 한 화면에서 선택.
2. **알림 설정 완료:** 경로 저장 및 알림 활성화 상태를 명시. 기본 안내는 버스 도착 30분 전부터. 가입·로그인은 완료 뒤에만 배치.
3. **결과 없음:** 별도 페이지를 강제하지 않고 경로 입력 화면 안에서 재검색·주변 정류장 찾기를 제공. 기존 입력값 유지.
4. **알림 상태:** 실시간 데이터가 확인되지 않으면 도착 시각을 단정하지 않고 갱신 상태 또는 안내 불가 상태를 표시.

**근거:** `brand.md`의 최소 2화면 핵심 흐름과 첫 사용의 이탈 방지 원칙을 유지한다.
