# Brand & Product UX — 버스 출발 알림 서비스

> 문서 유형: `brand.md`  
> 목적: 브랜드의 핵심 가치와 모바일 서비스의 사용자 여정·정보 구조·핵심 과업 흐름 정의  
> 근거: `상세페이지-7블록.txt`  
> 상태: UX 설계 초안 (소스에 없는 구현 사항은 **설계 가정**으로 표시)

## 1. 브랜드 정의

### 핵심 문제
출근 준비를 마치고 버스 정류장에 도착했지만, 버스가 1분 전에 출발해 지각한 경험. 사용자는 버스가 정류장에 도착하는 정확한 시간을 알기 어렵다.

### 가치 제안
미리 입력한 출근 경로와 집에서 정류장까지의 거리를 고려하여, 버스 도착 30분 전부터 남은 시간을 모바일 알림으로 안내한다. 사용자가 집에서 언제 나갈지 고민하지 않게 한다.

### 핵심 과업
**“출근 경로를 입력하면 버스 도착 사전 알림을 받는다.”**

- **입력:** 출근 경로
- **출력:** 버스 도착 30분 전부터 남은 시간을 알려주는 모바일 알림
- **과업 완료 기준:** 경로가 저장되고 알림이 활성화되어, 사용자에게 설정 완료가 확인됨
- **가격 원칙:** 광고 기반 무료 이용 (원본 소스)

### 소스 기반 근거
- **스토리:** 버스가 1분 먼저 출발하여 지각함
- **문제:** 버스 도착 시각을 정확히 모름
- **해결:** 정류장까지의 거리를 반영해 30분 전부터 사전 안내
- **경험:** 사전 알림으로 버스 도착 1분 전에 정류장에 도착한 사례
- **행동 유도:** 출근 경로를 입력하면 알림 설정 가능

## 2. 사용자 여정 맵

감정 척도: -2(매우 부정) ~ +2(매우 긍정). 점수는 조사 결과가 아닌 **설계 가정**.

| 단계 | 행동 | 생각 | 감정 | 접점 | 아픈 곳 | 화면 필요 |
|---|---|---|---:|---|---|---|
| 알게 됨 | 버스를 놓친 뒤 서비스를 발견 | “미리 알았다면 안 늦었을 텐데” | -2 | 검색·추천·광고 | 서비스 존재와 효용을 모름 | 아니오 |
| 고민 | 무료 여부와 알림 신뢰도를 살핌 | “정말 제때 알려줄까?” | -1 | 소개 콘텐츠·앱 설치 페이지 | 비용·정확도 불안 | 아니오 |
| 첫 사용 | 출근 경로를 입력하고 알림을 설정 | “이제 언제 나갈지 알겠네” | +1 | 경로 입력·설정 완료 | 긴 입력·정류장 검색 실패 | **예 — 화면 필요** |
| 반복 | 출근 전 알림을 보고 이동 | “오늘도 버스를 놓치지 않겠어” | +2 | 푸시 알림·도착 정보 | 예측 오차·알림 누락 | **예 — 화면 필요** |
| 추천 | 동료에게 서비스를 공유 | “출근할 때 유용해” | +2 | 메신저·공유 링크 | 공유 계기 부족 | 아니오 |

**감정 상승의 핵심:** 첫 설정을 빠르게 끝내는 경험과 실제로 제때 알림을 받는 경험.

## 3. 정보 구조도 (IA)

원칙: 상위 가지 4개, 핵심 과업 경로 깊이 2 이하, 나머지 깊이 3 이하.

```text
버스 출발 알림 서비스
├── 1. 출근 경로 설정 [핵심 경로] [탭바 후보]
│   ├── 출발지·탑승 정류장·버스 선택
│   └── 알림 설정 완료 [핵심 과업 완료]
├── 2. 내 알림 [탭바 후보]
│   ├── 버스 도착 예정 시간
│   ├── 집에서 나갈 시점
│   └── 알림 켜기·끄기
├── 3. 저장 경로 [탭바 후보]
│   ├── 출근 경로 목록
│   └── 경로 상세
│       └── 경로 수정·삭제
└── 4. 설정·공유
    ├── 알림 권한 관리
    ├── 서비스 공유
    └── 계정·로그인 [핵심 과업 완료 후]
```

- **핵심 경로:** 출근 경로 설정 → 알림 설정 완료
- **탭바 후보:** 경로 설정 / 내 알림 / 저장 경로
- **보조 메뉴:** 설정·공유
- **첫 사용 진입:** 별도 온보딩 없이 출근 경로 입력으로 바로 이동

## 4. 핵심 과업 흐름 카드

| 번호 | 화면 이름 | 사용자가 내리는 결정 하나 | 미리 채워둘 기본값 | 이탈 위험 및 대책 |
|---:|---|---|---|---|
| 1 | 출근 경로 입력 | “이 경로로 알림을 받을까?” | 현재 위치 출발지, 가까운 정류장 후보, 추천 버스 (**설계 가정**) | **긴 폼:** 한 화면 자동완성·추천. **빈 결과:** 화면 내 재검색·주변 정류장 제시 |
| 2 | 알림 설정 완료 | “설정을 마칠까?” | 도착 30분 전 알림, 도보 이동시간 자동 반영 (**설계 가정**) | **가입 벽:** 가입 없이 우선 저장하고, 계정은 완료 후 선택적으로 제공 |

### 화면 1 — 출근 경로 입력
- **목적:** 알림을 받을 출근 경로를 지정한다.
- **필드:** 출발지, 탑승 정류장, 버스 노선
- **주요 행동:** `이 경로로 알림 설정하기`
- **기본값:** 현재 위치 및 주변 정류장·노선 추천 (**설계 가정**, 위치 권한 또는 대체 검색 필요)
- **정책:** 정류장·버스 선택은 별도 페이지로 분리하지 않고 같은 화면의 검색·선택 UI로 처리

### 화면 2 — 알림 설정 완료
- **목적:** 저장 및 알림 활성화 결과를 확인한다.
- **표시:** 선택한 경로, 알림 시작 기준(도착 30분 전), 도보 이동시간 반영 여부
- **주요 행동:** `완료`
- **정책:** 로그인·회원가입은 이 화면 이후에만 노출 가능
- **주의:** 실제 알림이 동작하려면 운영체제 알림 권한이 필요하며, 거부 시 권한 설정 안내를 제공해야 함

### 탭 수
- **최소 1탭:** 모든 경로 값이 미리 채워진 경우 `알림 설정하기` 선택만 계산. 완료 버튼까지 누르면 2탭.
- **목표:** 핵심 과업 완료까지 3탭 이하.
- **제약:** 정류장과 노선을 수동 검색·선택하는 경우 실제 탭 수는 3회를 초과할 수 있음. 따라서 3탭 보장은 자동완성 성공 시에만 성립하며 사용성 테스트로 검증 필요.
- **초과 시 삭제할 화면:** 별도 `버스 검색 결과` 화면. 검색 결과를 경로 입력 화면의 인라인 목록으로 통합.

## 5. ‘결과 없음’ 화면 (예외 상태 1장)

> **검색 결과가 없어요**  
> 입력한 버스나 정류장을 찾지 못했어요. 이름을 바꾸거나 주변 정류장을 확인해 보세요.

- **주요 행동:** `주변 정류장 다시 찾기`
- **보조 행동:** `버스 번호 또는 정류장 다시 검색`
- **유지할 값:** 이전에 입력한 출발지·검색어·선택 내용
- **구현 방식:** 별도 필수 단계가 아닌 **경로 입력 화면 내부의 빈 결과 상태**
- **권한 예외:** 위치 접근이 불가능하면 정류장명 직접 검색 제공 (**설계 가정**)

## 6. 화면 필수성 검증

검증 질문: **“이 화면이 없으면 핵심 과업이 안 되나?”**

| 화면 | 필수 여부 | 처리 |
|---|---|---|
| 서비스 소개 | 아니오 | 핵심 흐름에서 삭제, 설치 페이지에서 설명 |
| 온보딩 | 아니오 | 삭제 |
| 로그인·회원가입 | 아니오 | 핵심 과업 완료 뒤로 이동 |
| 출근 경로 입력 | 예 | 유지 |
| 별도 버스 검색 결과 | 아니오 | 경로 입력 화면에 통합 |
| 별도 알림 시간 설정 | 아니오 | 도착 30분 전 기본값으로 통합 |
| 알림 설정 완료 | 예 | 유지 (저장·활성화 상태 확인) |
| 결과 없음 | 조건부 | 경로 입력 화면의 예외 상태로 유지 |
| 추천·공유 | 아니오 | 후속 기능으로 분리 |

**최종 필수 화면: 2개 — 출근 경로 입력 → 알림 설정 완료.**

## 7. 구현 전 확인할 가정

원본 소스는 서비스의 문제·해결·무료 제공 방식을 설명하며, 아래 기술·운영 조건은 명시하지 않는다.

1. 실시간 버스 도착 정보 제공처와 예측 정확도
2. 집에서 정류장까지 도보 시간 계산 방식
3. 30분 전 알림의 발송 주기 및 중단 조건
4. 알림·위치 권한 거부 시 대체 경로
5. 로그인 없는 경로 저장의 지속성 및 기기 변경 시 처리
6. 광고 노출 위치와 핵심 과업 방해 여부
